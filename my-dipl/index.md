# Diplomacy Agentic Implementation

## Overview 
A collaborative tool for managing diplomatic interactions and negotiations, adhering to DATC v3.0 standards.

## Features 
- Secure communication channels  
- Real-time collaboration  
- Wrangler-based deployment  

## Files 
- **map-graph.json**: Game map with 75 provinces, coastal/land split zones, and adjacency rules.  
- **ressources.md**: Official DATC repositories, rule guides, and JSON schema links.  
- **rules.json**: Adjudication logic, faction setup, and turn-phase mechanics.  
- **sockets.json**: WebSocket protocol for real-time game sync.  
- **test_cases.txt**: DATC-compliant test scenarios (e.g., convoy paradoxes).
